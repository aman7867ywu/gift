# Khushi Birthday Adventure ❤️

Premium romantic birthday microsite for Khushi (7 September 2010), nicknames Kucchu & Puchhu.

## Run
Open `index.html` in any modern browser. No build step or backend is required.

## Personalization
- Replace the demo SVGs in `images/` with your own photos, keeping the filenames:
  `01-kda.svg`, `02-mall-road.svg`, `03-iskcon.svg`, `04-moti-jheel.svg`,
  `05-ganga-barrage.svg`, `06-z-square.svg`, `07-us.svg`, `08-birthday.svg`.
  You can also change the HTML extensions to `.jpg`/`.png` if preferred.
- The route is intentionally a stylized itinerary, not an exact GPS navigation map.
- Secret password: `22092002`.
- Music is user-controlled (button only; no autoplay). The demo uses a remote royalty-free audio URL; for fully offline deployment, replace the audio source with your own locally licensed MP3 and set `music.src="audio/birthday.mp3"`.
